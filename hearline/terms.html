Hearline 이용약관

시행일 2026.11.26

1. 목적

Hearline은 이용자가 등록한 소스의 글과 오디오를 읽고 들을 수 있게 하는 도구임.

2. 콘텐츠 권리

앱은 콘텐츠를 제공하지 않음. 모든 글·오디오·이미지의 저작권은 각 권리자에게 있으며 앱은 받은 콘텐츠를 이용자 기기 밖으로 보관·배포하지 않음.

3. 이용자 책임

이용자는 등록한 소스와 사이트의 이용약관·저작권을 지킬 책임이 있으며 콘텐츠를 개인 용도로만 이용함. 로그인 계정을 타인과 공유하거나 받은 글을 재배포하지 않음.

4. 외부 서비스

외부 사이트, 음성 엔진, Gemini, 구글 드라이브 등은 각자의 약관을 따르며 그 이용 비용·한도(예 : API 키 사용료)는 이용자 부담임.

5. 유료 기능

앱 자체 기능 중 일부(프리미엄)는 1회 결제로 제공되며 결제와 환불은 Google Play 정책을 따름. 외부 콘텐츠 접근 자체는 판매하지 않음.

6. 면책

외부 콘텐츠의 정확성·제공 지속, 음성 낭독·글 변환 결과의 정확성을 보증하지 않음. 소스 사이트 사정으로 기능이 동작하지 않을 수 있음.

7. 변경·문의

변경 시 앱과 웹에서 알림. 문의 : gandalpe@gmail.com
